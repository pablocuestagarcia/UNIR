# Listas enlazadas 

Una **lista enlazada** es una estructura de datos lineal donde cada elemento (nodo) contiene:
* **Datos**: el valor almacenado.
* **Puntero/Referencia**: Dirección al siguiente nodo en la secuencia.

**Características principales**:
* No requiere memoria contigua
* Inserción/eliminaicón eficiente en cualquier posición.
* Acceso secuencial (no acceso directo por índice)
* Tamaño dinámico.


## Tipos de Listas Enlazadas

* **Simple**: cada nodo apunta al siguiente.
* **Doble**: cada nodo apunta al siguiente y al anterior.
* **Circular**: el último nodo apunta al primero
